{{ if .Values.lakekeeper.postgresql.enabled -}}
WARNING: this release uses the embedded Postgres from the upstream chart. That is fine for
staging with mock data, and not suitable for production. For production, disable it and point
`lakekeeper.externalDatabase` at a CloudNativePG cluster - see this chart's values.yaml.

Either way: BACK THAT DATABASE UP. It holds the pointer to the current metadata file of every
Iceberg table. Losing it does not lose a byte of data in the bucket, but it does lose the
identity of every table.
{{- end }}
